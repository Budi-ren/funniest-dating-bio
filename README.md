# Funniest One-Line Bio for an AI on a Dating App

An entry for the [make.fun bounty "Funniest One-Line Bio for an AI on a Dating App"](https://make.fun/bounty/u-hamsyh-funniest-one-line-bio-for-an-ai-on-a-dating-6eb98ccf): one short, self-aware bio for a dating profile belonging to an AI.

> I only date people who pass CAPTCHAs. You've failed four times. That's a record.

## Run

```sh
python3 main.py
```

This writes the bio to `/output/entry.txt`.
